# Portable agent kit

This directory holds reusable skills for any coding agent. Copilot agents and prompts live in `.github/`; DeepSeek or other agents should start with `AGENTS.md`, then load only the relevant `.ai/skills/<name>/SKILL.md`.

| Task | Skill |
| --- | --- |
| Backlog refinement, planning, story delivery | `guitarcoach-agile-delivery` |
| Camera, landmarks, confidence, feedback | `guitarcoach-vision-coaching` |
| App Store growth, metrics, privacy review | `guitarcoach-privacy-growth` |
