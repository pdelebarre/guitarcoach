# Deliver one slice

1. Read `AGENTS.md`, the selected GitHub issue, and only the relevant product or architecture document.
2. Restate the learner outcome and write 3–5 testable acceptance criteria. Identify privacy and accessibility implications.
3. Split anything larger than one focused session. Order work by risk: validate highest-uncertainty assumptions first.
4. Implement or specify one vertical slice. Do not mix refactors, future platform work, and unrelated fixes.
5. Verify the slice and leave an issue handoff: outcome, checks, risk, and next smallest slice.

Use `references/story-template.md` for an issue body or handoff. Keep prose short; link to source files/issues instead of copying them.
